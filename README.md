# Setor de Produção

Sistema de controle de produção da equipe.

## Como rodar

```bash
npm install
npm run dev
```

Acesse http://localhost:3000

## Telas

- **Fichas Técnicas** — front end concluído
- **Ordens de Produção** — front end concluído
- **Produtos** — a implementar
- **Kanban** — a implementar
- **Dashboard** — a implementar

- Next.js 16

- CSS puro
